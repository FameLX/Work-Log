Stable

Replaces a native <input type="time">. Two scrollable columns (hour, 5-minute steps) in a small dropdown; also accepts direct typing with auto-formatting.

Usage

// read the value elsewhere exactly as before
document.getElementById('my-input-id').value; // "HH:MM"

Date Picker

Stable

date-picker.js · date-picker.css · needs date-mask.js

Replaces a native <input type="date">. The trigger is a real text field — type DD/MM/YYYY directly, or click it to open the shared popover with month/year selects and a day grid.

container.appendChild(trigger);

// read the value elsewhere

Date + Time Picker

Stable

datetime-picker.js · datetime-picker.css · needs date-mask.js + time-mask.js

Replaces <input type="datetime-local">. Type DDMMYYYY[HHMM] directly into the trigger, or click it for the same calendar as the date-only picker plus a merged HH:MM field — picking a day doesn't close the panel, so there's time to set the time too. Stores a full UTC ISO string; optionally edited against a fixed offset (e.g. GMT+7) instead of raw UTC.

Usage 
const trigger = createDateTimeTrigger('due-at', '2026-07-15T09:30:00Z'); // '' for unset
container.appendChild(trigger);

// edit against a fixed local reference instead of raw UTC
createDateTimeTrigger('due-at', iso, { offsetMinutes: 420 }); // GMT+7

// read the value elsewhere
document.getElementById('due-at').dataset.iso; // "YYYY-MM-DDTHH:MM:SSZ"

Timezone-Aware DateTime Converter

Stable

timezone-converter.js

Operators always type wall-clock time in ONE fixed "home" zone; this converts it to any other IANA zone through a real UTC instant — so daylight saving is handled correctly (a summer flight to London reads GMT+1, a winter one GMT+0) — and flags a midnight-crossing conversion with a (+1d)/(-1d) marker instead of silently eating it.

→
Usage 
convertPreview('2026-07-25', '23:30', 'Asia/Bangkok', 'Europe/London');
// -> { text: "25/07/2026  17:30", shiftDays: 0 }

gmtOffsetLabel('Europe/London', '2026-07-25'); // -> "GMT+1" (DST-aware)

Settings Draft/Dirty/Discard Guard

Stable

settings-draft.js (behavior only, no CSS)

Generic "open a panel, edit freely, Save or Discard" flow. Not tied to any fields — you supply a getState/applyState pair and this tracks a snapshot + dirty flag around it. Edit the field below, then try Close: it'll prompt because it's dirty. Save re-baselines so Close no longer prompts.

Usage 
const guard = createDraftGuard(
  () => ({ theme: currentTheme }),         // getState
  (state) => { currentTheme = state.theme; render(); }  // applyState
);
input.addEventListener('input', () => { currentTheme = input.value; guard.markDirty(); });
closeBtn.onclick = () => guard.confirmDiscardIfDirty(() => panel.close());
saveBtn.onclick = () => { persist(); guard.snapshot(); };

Firestore Live Cross-Device Sync

Stable

firestore-sync.js · firestore-sync.css · needs the Firebase JS SDK + a real project

Turns a localStorage-only array into a live, multi-device-synced Firestore collection — any client's writes propagate to every other open client via onSnapshot; there's no manual "save all". Plus a connecting/connected/error status pill. No real Firebase project wired into this demo — the pill below is driven directly to show its three states, and a real createFirestoreSync(...) call would drive it automatically via onStatusChange.

Usage 
// after the Firebase SDK module block sets window._db / window._collection / etc:
const sync = createFirestoreSync({
  db: window._db,
  firestoreFns: { collection: window._collection, doc: window._doc,
    onSnapshot: window._onSnapshot, setDoc: window._setDoc, deleteDoc: window._deleteDoc },
  collectionPath: 'entries',
  onSnapshotUpdate: (items) => { myItems = items; renderUI(); },
  onStatusChange: (status) => pill.setStatus(status),
});
sync.saveItem(item);   // setDoc, item.id required
sync.deleteItem(id);   // deleteDoc

Connect to Google Calendar

Stable

gcal-connect.js · gcal-connect.css (optional) · needs a Google OAuth Client ID

Client-side Google OAuth 2.0 implicit flow — no server, no client secret. Opens Google's consent popup, relays the access_token back via postMessage, and stores it in localStorage. The token is a Bearer for the Calendar/Tasks REST API. Generalised from the Work Log app. Key caveat: the redirect_uri must be a page that also loads this script (usually the same page) — that page's auto-capture step is what hands the token home. Tokens last ~1 hour; re-run connect() to refresh.

Calendar connected Session expired — Reconnect

Three states: idle · connected · expired. The first is wired to the real module in demo mode (no Client ID) — clicking it just warns, since live OAuth needs a registered origin.

Usage 
// 1. Google Cloud Console: OAuth Client ID (Web). Add your page URL to both
//    "Authorised JavaScript origins" AND "Authorised redirect URIs".

<link rel="stylesheet" href="gcal-connect.css">
<script src="gcal-connect.js"></script>

const gcal = GCalConnect.init({
  clientId:      'xxxx.apps.googleusercontent.com',
  redirectUri:   location.origin + location.pathname, // must host this script
  scopes:        ['https://www.googleapis.com/auth/calendar.events'],
  storagePrefix: 'myapp',   // localStorage: myapp_gcal_token / _client_id
  onChange: (s) => {          // s = { connected, expired, token }
    pill.classList.toggle('connected', s.connected && !s.expired);
    pill.classList.toggle('expired', s.expired);
  },
});

pill.onclick = () => gcal.isConnected() ? gcal.disconnect() : gcal.connect();

// use the token as a Bearer against the Google REST API
fetch('https://www.googleapis.com/calendar/v3/calendars/primary/events', {
  headers: { Authorization: 'Bearer ' + gcal.getToken() }
});

gcal.applyToken(t); // manual fallback if the popup was blocked
gcal.verify();      // probe token; flips to expired on 401

Smart Help Tooltip (Viewport-Clamped)

Stable

smart-tooltip.js · smart-tooltip.css

A "?" badge that shows help text in a single shared position:fixed bubble instead of a per-icon CSS tooltip — it survives inside scrolling/overflow:auto panels (where an in-flow bubble gets clipped) and auto-flips above/below the badge to stay fully on screen. A different mechanism from the Input Guidance Tooltip above — that one is pure CSS for simple, non-scrolling forms; this one is for panels that scroll, or where the tooltip text is generated dynamically.

Scroll down inside this box — the badge still finds room for its bubble.

Usage 
<label>Flight Number<span class="st-icon" data-tip="Code on the ticket, e.g. TG320.">?</span></label>

initSmartTooltips(); // call once — delegates to every .st-icon on the page, present or future

A chevron-rotate disclosure for hiding rarely-used optional fields — starts collapsed to keep a form short, expands on click. Deliberately tiny: one class for the toggle row, one for the chevron, no framework.

▸ Header / Transaction (optional)
Usage 
<div class="cs-toggle" onclick="toggleSection('sec-body', this)">
  <span class="cs-chevron">▸</span> Optional fields
</div>
<div id="sec-body" style="display:none;">...</div>

function toggleSection(bodyId, toggleEl) {
  const body = document.getElementById(bodyId);
  const open = body.style.display === 'none';
  body.style.display = open ? 'block' : 'none';
  toggleEl.classList.toggle('open', open);
}
